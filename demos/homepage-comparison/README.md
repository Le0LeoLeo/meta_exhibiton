# Meta EXB homepage comparison

Local-only presentation demo with two selectable homepage directions, responsive width controls, exhibit previews, and illustrative creation entry. It does not connect to accounts, uploads, production APIs, or deployment.

From `web_ui_new/`:

```powershell
npm run dev -- --config demos/homepage-comparison/vite.config.ts
npm run build -- --config demos/homepage-comparison/vite.config.ts
```

Local URL: http://127.0.0.1:5188/

All new source and build output stay inside this demo directory. Existing application routes and configuration are unchanged. Gallery visuals are generated concept imagery; painting.jpg reuses the project's public demo artwork (met-436535.jpg).
