# PBR Texture Attribution

Only CC0 or project-owned assets may be added to this directory. Each material
set must contain `basecolor.jpg`, `normal.jpg`, `roughness.jpg`, and `ao.jpg`.

The bundled files are the 1K JPG diffuse, OpenGL normal, roughness, and ambient
occlusion maps supplied by Poly Haven. File integrity was checked against the
MD5 values returned by the official Poly Haven API.
