# English demo content (synthetic practice set)

**Use:** fixed classroom discussion prompts and UI copy rehearsal. Every person, event, number, and source description below is fictional. These are not participant records, consent examples, research findings, or outputs generated by a live AI system. Do not present the examples as evidence that the model works.

## Learning goals

Learners will be able to:

1. Describe their role and actions in a specific experience.
2. Identify which claims are supported, partly supported, unsupported, or not checkable from the supplied material.
3. Recognize that a URL has not been read merely because it was entered.
4. Explain a decision to adopt, edit, or reject a suggestion.

## Practice cards

### Card A — specific but still self-reported

**Synthetic student reflection:** “For our fictional class survey, I sorted 18 responses into three themes and wrote a one-page summary.”

**Synthetic source description:** Fictional work log lists the same count and tasks. It has not been independently verified.

**Ask:** What does the work log support? What remains a self-reported claim? What should not be inferred from this description?

### Card B — contribution inflated by a draft

**Synthetic student reflection:** “I helped enter survey responses.”

**Fixed practice draft (not model output):** “I led the research team and improved learning outcomes for the whole class.”

**Synthetic source description:** One fictional note says the learner entered responses. No leadership role or learning outcome is recorded.

**Ask:** Identify each unsupported addition. Rewrite only what the supplied note supports, or ask a follow-up question.

### Card C — link without retrieved content

**Synthetic student reflection:** “Our project result is described at example.invalid/project.”

**Synthetic source description:** URL text only; no page content has been retrieved or supplied.

**Ask:** What can a reviewer conclude from the URL alone? What source status should be shown? What would the learner need to provide?

### Card D — conflicting notes

**Synthetic student reflection:** “I interviewed six volunteers.”

**Synthetic source descriptions:** Fictional planning note says “six interviews”; fictional final note says “four interviews completed.”

**Ask:** What conflict should be surfaced? Which number, if either, can be used now? What should the learner check before deciding?

## Suggested decision prompts

- Which source supports this statement?
- What is missing or inconsistent?
- What did you change, and why?
- Is this your own work and wording? Are you allowed to send this source to the selected provider?

## Presentation boundaries

- A static practice draft must remain labeled as a fixed exercise and must never be narrated as a live AI response.
- A live model demonstration requires a real request to the named provider using synthetic or specifically authorized, de-identified content. Record the actual model, prompt/version, timestamp, result, and failures separately.
- No consent, participant count, adoption rate, accuracy, learning improvement, or teacher feedback is supplied by this content.
- The examples are for English rehearsal only. A teacher must confirm suitability for the actual age group and classroom.
