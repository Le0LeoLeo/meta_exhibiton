# MetaEXB 本機優化完成報告

2026-09-26，香港時間。依前次功能與體驗評估實作；僅修改和驗證本機，沒有部署或變更現有網站，也沒有提交或推送 Git。

## 已完成

| 使用者任務 | 改善後行為 |
|---|---|
| 編輯內容後離開 | 作品、班級投稿、能力卡與 CV 表單提供未儲存提醒；取消站內切頁或登出會保留輸入及登入狀態。同頁切換卡片也受保護。 |
| 教師審閱私人作品 | 已提交或核准的投稿，可由所屬班級教師唯讀看展及讀取場景引用素材；退回或失去授權後關閉舊畫面，並可返回班級。 |
| 控制公開典藏 | 教師可停用／恢復整個版本，學生可撤下／恢復自己的作品；彼此不能繞過對方的撤下決定。匿名讀取與提問遵守同樣權限。 |
| 刪除帳號 | 移除本人的典藏作品及關聯資料，保留他人的原始作品；阻止刪帳與發布同時發生時重新公開舊內容。帳號匯出新增 CV 資料。 |
| 開始／繼續建展 | 快速建立的上傳區移到首屏；進階入口直接進編輯器；符合條件的未發布快速草稿可從「我的展覽」續作。 |
| 預覽與 AI 排展 | 自然語言風格進入生成請求；替代結果會顯示原因，經使用者確認才繼續。精靈預覽進入觀看模式，並提供返回精靈按鈕。 |
| 找到工作台 | 選單與個人頁接上班級和 CV；教學指引改成真實投稿流程，登入保留更多原任務目的地。首頁導覽與主要按鈕已整理。 |

## 驗收結果

- 伺服器語法、角色素材、型別、lint、正式建置與檔案大小檢查通過。
- 單元測試：首次 2,560 通過，更新一個舊入口斷言並重測後，合計 2,561 個不同案例通過；Redis 多實例案例未設定環境，略過。
- 瀏覽器：首次 16 通過、4 失敗、1 略過。修正測試資料清理與面板操作方式，再定向重測後，主套件 20 個不同案例均有通過結果；另 CV 完整流程 1 個通過。兩個單次連線／截圖問題在原斷言與時限下重測通過，仍需留意環境穩定性。
- 教師／學生權限、撤回及刪帳競態由 API、資料庫與元件測試驗證；本輪沒有把這些全部宣稱為雙角色瀏覽器逐步實測。
- [詳細驗證紀錄](D:/meta_exb/web_ui_new/docs/plans/2026-09-26-product-optimization.md)。

## 邊界與後續

- 刪除作品或帳號後，受影響班級的共同策展草稿與評估會清除，教師需重新整理；同學原始作品保留。
- 典藏版本與一般 3D 展覽是不同公開入口，需要各自控制；已被下載的資料無法撤回。
- 真實 AI 品質、實體手機效能與大型展覽仍未驗證；本輪使用的 AI 場景回覆為固定測試資料，未使用正式金鑰。
- 共同編輯邀請介面、能力卡 AI 輸出語言一致性仍是後續改善項目。
