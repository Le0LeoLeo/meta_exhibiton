瀏覽器已有用戶登入狀態，本次沿用該狀態，沒有登出。沒有建立帳號、上傳作品、修改或發布展覽，也沒有修改應用程式或部署。登入與註冊頁僅檢查入口及提示，未驗證新用戶的完整登入／註冊流程。

## 發現與建議

### 1. P1：公開展覽進場只看到大片牆面

- 網址：https://metaexb.com/exhibitions/4de16416-ad2f-4a4a-9ebb-fb72a4a5f567
- 重現：展覽列表 →「我的作品展」→「進入展覽」→ 選擇個人參展 → 確定。
- 實際：3D 畫面只見近距離淺色牆面與控制介面，未見作品或入口。切至 2D 再返回 3D 可重現；使用「加入展廳」貼上相同公開連結，在窄螢幕亦重現。
- 對照：同一展覽切換 2D 後能顯示「課表」作品及作者資料。官方示範展的 3D 能正常顯示名畫。
- 影響：首次參觀者難以辨認自己是否成功進入展館，也沒有明顯的「回到入口／重設視角」按鈕。
- 建議：檢查進場位置、相機朝向及與牆體的距離，讓進場第一眼看見展場；補上回到入口功能。
- 限制：尚未確定是該展覽場景資料或共用進場邏輯造成。嘗試滑鼠／鍵盤及窄螢幕拖曳未取得清楚展場畫面，但自動操作不能代替真實長按及觸控，因此不據此宣稱所有移動控制失效。
- 證據：[桌面截圖](public-3d-initial.png)、[手機尺寸截圖](public-3d-mobile.png)。

### 2. P1：忘記密碼沒有可完成的恢復流程

- 重現：登入頁 →「忘記密碼？」。
- 實際提示：「密碼重設寄信服務尚未啟用，這次沒有寄出任何郵件。已登入的用戶可在個人資料頁更改密碼。」
- 影響：忘記密碼且已登出的用戶無法經此入口恢復帳號；已登入才能改密碼的說明不能解決這種情境。
- 建議：提供可完成的帳號恢復流程或有效替代協助管道。
- 定性：這是頁面明確揭露的服務缺口，不是本次測得的寄信故障。沒有提交電郵或更改密碼。
- 證據：[截圖](password-recovery-unavailable.png)。本地對照：`src/app/pages/Login.tsx:145–151`。

### 3. P2：資源頁引導至尚未啟用的支援服務

- 重現：資源 → 頁尾「聯繫支援團隊」所指向的支援頁。
- 實際：資源頁表示「我們將竭誠為您服務」，但支援頁表明客服、電郵及電話支援均未啟用，無法接收支援申請。教學資源也尚未上架。
- 影響：FAQ 無法解答時，用戶沒有下一步可走。
- 建議：啟用至少一個有效聯絡管道，或把資源頁行動文字改成「搜尋常見問題」，清楚說明目前服務範圍。
- 定性：服務與文案流程缺口；支援頁有誠實揭露，沒有假裝已送出申請。

### 4. P2：主要建展入口的素材格式與首頁預期有落差

- 重現：首頁看到「PDF / IMG / Video」及文件／影片介紹 →「上傳作品建展」。
- 實際：快速建展頁只提供靜態 JPG、PNG、WebP，最多 30 件、每件 15 MB，未見加入影片／文件的替代入口。
- 影響：持有 PDF 或影片的新用戶容易在主要入口停住。
- 建議：在按鈕或入口說明「圖片快速建展」，並提供其他素材格式的明確操作路徑。
- 定性：入口引導問題；本次沒有測試完整編輯器，因此不代表整個產品不支援其他格式。

### 5. P3：已登入用戶仍被引導註冊

- 重現：已登入 → 虛擬展廳頁底部 →「立即註冊」。
- 實際：顯示「註冊即可開始建立您的展廳」，點擊後進入完整建立帳號表單；頂部仍顯示既有用戶與登出按鈕。
- 影響：容易令用戶誤以為需要另一個帳號才能繼續建展。
- 建議：依登入狀態改成「建立展覽」或「我的展覽」。
- 本地對照：`src/app/pages/VirtualGallery.tsx:381`。
