# 師生協作與作品典藏

2026-09-12 已部署香港正式站。入口：[畢業展工作台](https://metaexb.com/graduation)。

## 教師

1. 建立班級展，將邀請碼交給參展學生。
2. 用「收件與審核進度」查看加入人數、尚未建立作品及投稿狀態，按狀態篩選作品。需要延長收件時，展開邀請碼下方的截止時間設定。
3. 審閱作品，填寫意見後核准或退回；退回必須說明修改要求。私人評閱只供作者與教師查看。
4. 產生分組建議，檢查作品與理由，編輯觀眾導覽。AI 無法使用時會明確顯示規則備援，不自動代寫導覽。
5. 勾選確認並儲存分組。作品或審核狀態改變後，需要重新確認目前版本。
6. 可展開「記錄本次策展成效」，填寫同批作品的人工整理時間、本次建議與修改的總時間、品質評分及測試觀察。數據由評估者自填，不能直接當作已證實的 AI 效益。
7. 確認已核准作品及參展者同意的公開範圍，建立公開典藏。分享該版本網址；新的發布版本不會覆寫舊版文字。

## 學生與回饋

- 使用邀請碼加入，填寫作品名稱、研究問題、理念、過程與成果。先儲存，再提交教師審核。
- 退回後可修改再提交。已核准作品可「建立修改版本」，重新完成審核；原公開典藏保持定稿。
- 登入觀眾可在公開作品頁展開問答，向作者提問。作者與該班教師在「觀眾提問待辦」回覆；必要時可隱藏整則問答。
- 展後問答是持續更新的公開討論，與發布時凍結的公開評語分開。問答清單最多顯示 100 則，待辦優先顯示未回覆問題。

## 觀展與作品集

- 公開頁提供作品目錄與搜尋。已連結且仍公開的展覽可以選擇 2D 圖文或 3D 觀看；2D 直達入口不先啟動 3D 場景。
- 「我的作品集」顯示目前作品及參與過的班級典藏版本。展開「創作版本紀錄」可選擇歷次儲存、提交與審核版本。
- 「下載可列印作品集」產生獨立 HTML，可用瀏覽器開啟、列印或另存 PDF；只包含創作文字，不包含私人評閱。版本區內的下載按鈕會匯出選定版本。
- 「下載版本資料」保留完整個人版本 JSON；其中可能含私人審核意見，分享前請確認內容。帳戶資料匯出也包含自己的版本與相關問答。

版本保存自本次功能啟用時的現有版本開始，無法重建更早已覆寫的修改。3D 展覽仍是受目前公開權限控制的連結，不是素材永久快照。真實教學成效及實體低階裝置效能，仍需後續試點測量。

## 本機候選更新（2026-09-26，尚未部署）

- 教師可停止或恢復整個典藏版本的公開存取；作者可在「我的作品集」撤下或恢復自己在指定版本中的作品。撤下會同時停用該範圍的公開問答，其他版本及獨立 3D 展覽需分別管理。
- 刪除作者帳戶會從已發布典藏移除該作者的作品與相關問答，保留同學作品。共享分區、導覽及策展評估可能包含作者資料，因此會一併清除；教師需以剩餘作品重新整理分區。刪除班級建立者帳戶仍會刪除其班級與典藏。
- 發布期間若來源作品被刪除、修改或審核狀態改變，發布會中止並要求重新確認，不會重新寫入已刪除作者的快照。已被他人下載的副本無法收回。
