# 展覽數據完善

使用者要求：將現有展覽數據後台完善為可用的參觀分析。

## 實作範圍

- 將參觀統計與登入使用者的 AI 導覽記憶分開；新資料不回填成歷史訪客數。
- 2D、3D 觀展統一記錄匿名瀏覽器識別、參觀工作階段與前景停留時間，登入作者不計入。
- 重複心跳不重複累加；服務端限制時間增量、檢查展覽存取權和作品 ID。
- 後台分開展示瀏覽器訪客與參觀次數，加入 7／30／90 日篩選、展覽篩選、香港日期趨勢及平均停留。
- 說明量測開始時間、瀏覽器識別限制，以及視窗隱藏不計時的口徑。

## 驗收

1. 針對匿名／登入／作者／私有分享權限、重複心跳、日期與工作階段統計寫測試。
2. 驗證 2D／3D 切換及前背景切換，不依賴 AI 啟用。
3. 完整 npm check 與乾淨香港白名單建置。
4. 隔離 staging 以本輪合成帳戶測試 API、重啟資料持久化與資料清理。
5. 更新既有香港 production，保留環境、用戶資料和 volumes；核對 HTTPS、ready、容器與公開端口。

## 數據口徑與限制

- 不重複瀏覽器不是實際人數；清除儲存／換裝置會重新識別，無帳戶或 IP 指紋關聯。未登入的作者無法可靠辨識並排除。
- 工作階段儲存在分頁，重新載入／2D、3D 切換延續；閒置 30 分鐘建立新階段。不同分頁可形成不同參觀次數。
- 停留只計可見分頁，並非保證使用者專注。作品時間指 3D 開啟詳情，或 2D 顯示至少一半且比例最高的作品。
- 前端每 15 秒傳送累計值；離頁最佳努力補送。網路中斷可能少計，重送不重複加總。伺服器每次最多接受 60 秒；跨午夜最多 60 秒歸入接收當天。每日次數是當天有活動的工作階段，因此跨日合計可大於整段去重次數。
- 舊 AI 記憶保留但不混入新統計。隱私頁同步說明隨機瀏覽器識別碼用途。
