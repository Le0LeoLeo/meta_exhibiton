# Edit 編輯器 UI 優化

完成：2026-09-05 18:24 HKT；已部署香港正式站。

- 頂部按鈕分為模式／狀態與編輯操作；對齊和分佈改為可用鍵盤操作的選單，保留原有數量限制與操作。
- 左側新增工具提供文字標籤；模型庫、設定與屬性面板統一尺寸、邊界、字體和深色表單。移除重複的快捷鍵說明，批量設定預設收合。

- 模型庫、更多工具、連線面板互斥；Esc 關閉並返回啟動按鈕，不清除展品選取。匯入入口支援鍵盤操作。
- 統一輸入框、色彩選擇、滑桿、停用狀態和焦點提示，尊重減少動畫偏好；修正燈條與隔間牆操作的深色對比。
- 補齊文字、模型、位置及裝飾屬性共 37 個翻譯鍵，繁中／簡中／英文共 111 則文字；補上多項表單的可及名稱。
