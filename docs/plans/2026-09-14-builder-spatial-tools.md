# Builder Spatial Tools Implementation Plan

**Goal:** Let the existing exhibition agent arrange protected artworks into up to three named wall sections and create bounded partitions with an explicit central aisle, with reviewable previews and conflict-safe application.

**Architecture:** Extend the existing validated operation plan with semantic operations and a deterministic spatial helper. Keep the current renderer, SQLite sessions, preview-first flow, revision budget and protected media. Expose compact wall capacity and explicit operation schemas to the model. Do not execute model-generated JavaScript. Existing session authorization and version checks remain authoritative.

**Tech Stack:** Express, Zod, React, Zustand, Three.js, Vitest, existing HK release pipeline.

## Tasks and acceptance

1. Add `server/services/exhibitionSpatialTools.js` and its tests. Arrange paintings on north/east/west walls using frame dimensions and scale; reserve edges, reject unknown/duplicate/locked IDs, insufficient wall/vertical capacity and conflicting existing displays. Add named signs above works and bounded split partitions outside a central aisle. Reject unsupported multi-room floor plans rather than silently treating them as a rectangle.
2. Extend `exhibitionSceneOperations.js`, `exhibitionSceneContext.js` and `exhibitionSceneService.js`. Advertise actual Zod operation schemas and wall context. Keep batches atomic; surface specific rejected-operation warnings without replacing the existing scene. Add prompt/service regressions.
3. Add deterministic partition boundary/aisle checks to `exhibitionScenePreflight.js`. Preserve geometry normalization behavior for existing operations and check semantic operations after normalization.
4. Guard `useEditorAiBuilder.ts` apply against current scene changes since generation, including room/floorplan/material changes. Add three-language capability and conflict copy, and component regressions.
5. Run focused tests, typecheck, lint, server check and fresh build/budget checks. Validate semantic tools with a real provider using synthetic inputs where current environment permits; browser acceptance must distinguish deterministic responses from live model quality.
6. Prepare a whitelisted HK release, compare runtime delta, validate isolated staging/restart/restore, deploy existing production preserving secrets/data/certificates/backups, and verify public hashes/readiness/TLS/ports. Record actual outcomes below.

No Git operations or subagents. This first release supports rectangular outer-wall sections and split partitions; arbitrary room topology, partition-mounted paintings, background jobs and external MCP are outside this bounded release.

## Execution

- Added two schema-validated semantic operations: `arrange-exhibition-sections` and `create-exhibition-divider`. Wall packing uses frame sizes/scales and caption bounds; the section sign is placed above the works. Capacity/lock/duplicate/occupancy/floor-plan failures reject the whole candidate batch with an actionable reason. Fallback now preserves the original scene rather than normalizing it on failure.
- Added wall-capacity/display context and the actual JSON operation schema to the model prompt. Semantic batches preserve unrelated items and floor-plan records through the legacy normalization stage. Generated divider boundaries and the minimum central gap are checked in deterministic preflight. The gap is not a claim of an entirely obstruction-free route.
- Editor apply compares the current snapshot to the original generation baseline; late local/collaborative edits block stale whole-scene application. Added three-language capability and conflict messages. Existing unreviewed status remains visible in version history.

## Use

Open a single rectangular gallery with unlocked artworks, then More → AI Builder. Example: “把現有九件作品按標題分成歷史、當代、未來三個展區，分別排列在北、西、東牆，加上展區標題。另在 z=6 建立橫向分隔，中央保留 2.4 米通道。保留所有作品與媒體，不添加家具。” Review the preview and warnings, run review if needed, then explicitly apply. If another edit happened after generation, regenerate against that current scene.
