# Mini Box Implementation Plan

**Goal:** Let an owner create a personal box, retain and manage pictures, append pictures without moving existing objects, and share the latest confirmed scene through a stable link.

**Architecture:** Keep gallery IDs, existing editor and share routes. Add box-content relationships and explicit library retention to media; visitor media access for retained content follows confirmed scene references. Use an independent SQLite connection per write transaction, gallery revisions and idempotent operations. Deterministic additive placement preserves all old objects; unsupported/full layouts leave content pending.

**Tech Stack:** Existing React/TypeScript, Express, SQLite, Three.js, Vitest.

This plan is executed in the current authorized workspace. No commits, branch changes or subagents. Existing files and runtime data are preserved.

## 1. Data and service
- Create `server/repositories/boxRepository.js`, `server/services/boxLayout.js`, `server/routes/boxRoutes.js` and focused integration/layout tests.
- Modify `server/db.js` for additive tables, retention flag and content-preserving migration; register routes in `server/index.js`.
- Test create, ownership, legacy import, atomic apply, replay, stale revisions, remove/update, persistence and deletion semantics.
- Add content export and retention protection; scope public media reads to confirmed references for library assets.

## 2. Owner experience
- Create `src/app/features/boxes/` list/detail pages and `src/app/api/boxes.ts`.
- Add `/boxes` and `/boxes/:id` to `src/app/routes.ts`, add navigation and translations in all three catalogs.
- Reuse upload, 3D preview/editor and share APIs. Provide image list, upload progress/errors, candidate preview, confirmation, retry, metadata editing, removal and library reattachment.
- Keep old routes and links. Default new boxes to private; sharing offers a stable viewer link and revocation.

## 3. Validation

- Browser acceptance: create five images, customize existing placement, add three, confirm old scene unchanged; reload, inspect share, revoke. Use isolated synthetic data.
- Verify smartphone-width layout, empty/loading/error states and i18n.
