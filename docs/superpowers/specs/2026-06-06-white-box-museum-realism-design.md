# 當代白盒博物館真實感改造設計

日期：2026-06-06  
狀態：已獲使用者批准

## 目標

在保留現有 Three.js、React Three Fiber、自由房間尺寸及平面圖編輯能力的前提下，將預設展廳和所有新建展覽提升為可信的當代白盒博物館空間。

成品應乾淨、明亮、克制，讓展品成為視覺主角。畫面須兼顧桌面與手機，並透過自動品質分級保持流暢。此次不更換 3D engine。

## 現況問題

- 房間主要由均勻盒狀幾何構成，缺少牆腳線、收口、門框及燈軌等建築尺度線索。
- 牆面及地面主要使用 SVG 紋理，欠缺可信的法線、粗糙度與環境遮蔽細節。
- 深藍背景、濃霧及平均照明令空間偏向遊戲場景，而非博物館。
- 陰影解析度偏低，燈光沒有按展品位置形成清晰的視覺層次。
- 公開展覽存在 React maximum update depth 問題；未登入導向亦可能重複疊加 `returnTo`。

## 選定方向

採用模組化展館系統，而非只換材質或以完整 GLB 展館取代現有房間。

此方案能增加建築與光影細節，同時保留使用者自由調整空間、移動展品及建立平面圖的能力。完整 GLB 只用於小型裝飾或可重用建築部件，不作為整個展館的固定外殼。

## 空間設計

### 建築表現

- 保留現有房間、牆段及平面圖拓撲作為主要幾何來源。
- 為牆段生成模組化牆腳線、頂部收口及轉角細節。
- 為可辨識入口加入簡潔門框或開口收邊。
- 天花加入低調的嵌入式邊槽和軌道燈系統。
- 建築細節須使用真實世界尺寸，避免裝飾比例隨房間尺寸失真。
- 裝飾幾何不得攔截展品選取、牆面放置或玩家碰撞事件。

### 預設風格

- 牆面：偏暖白色細灰泥或石灰塗料。
- 地面：自然淺木地板；可切換至中性微水泥。
- 天花：低反射暖白表面。
- 金屬：霧面黑或深灰燈軌與小型五金。
- 色彩保持中性，不使用明顯漸變、彩色霧或裝飾性 bloom。

## 材質系統

### PBR 資產

- 允許加入外部 CC0 PBR 材質及小型 GLB 建築資產。
- 材質最少包含 base color、normal 及 roughness；有合理來源時加入 ambient occlusion。
- 優先使用可壓縮、可平鋪、色彩中性的博物館材質。
- 記錄資產來源及授權至 `ATTRIBUTIONS.md`。

### 紋理處理

- 紋理重複比例以世界尺寸計算，不再只使用固定 tiling 數字。
- 木地板紋理方向應跟隨房間主要軸線，避免每個房間任意旋轉。
- 正確設定 sRGB 與線性資料貼圖的 color space。
- 設定 anisotropy 上限，改善斜視角地板清晰度。
- 桌面可使用較高解析度材質；手機使用壓縮或較低解析度版本。

### 回退行為

- 材質下載或解碼失敗時，使用中性 `MeshStandardMaterial` 回退。
- 單一資產失敗不得令 Canvas、房間或整個展覽黑屏。
- 預載畫面須反映必要資產進度，但不能因非必要裝飾永久停留。

## 燈光與渲染

### 基礎照明

- HDRI 只提供柔和環境反射及低強度間接光，不直接主導背景色。
- 移除或大幅減弱深藍背景與濃霧；白盒展館使用中性、明亮的空間背景。
- 以天花反射光和低強度環境光建立可讀性，避免所有表面平均發亮。
- 保留 ACES Filmic tone mapping，按白色材質重新校準 exposure。

### 展品照明

- 建立模組化軌道燈，沿房間或牆段自動排列。
- 射燈根據畫作、文字展板、雕塑及展台的位置產生目標。
- 每盞燈須限制距離、角度、半影及影響範圍。
- 優先照亮展品，牆面保留適量明暗變化。
- 編輯模式中新增、移動或刪除展品後，燈光配置須可重新計算。

### 陰影及後處理

- 桌面品質模式提高主要陰影解析度，並收緊 shadow camera 範圍。
- 使用穩定的 soft shadow、bias 及 normal bias，避免表面 acne 和漂浮感。
- 品質模式加入克制的 SSAO 或等價環境遮蔽。
- 可使用輕量接觸陰影加強展台、座椅及雕塑與地面的連接感。
- 不加入明顯 bloom、景深或濃 volumetric fog。

## 模組邊界

建議新增以下可獨立理解及測試的模組：

- `MuseumEnvironment`：環境反射、背景、tone mapping 協調及全局基礎光。
- `ArchitecturalDetails`：牆腳線、頂部收口、門框及天花細節。
- `TrackLighting`：燈軌幾何、展品目標選擇及射燈配置。
- `museumMaterials`：PBR 貼圖載入、world-scale tiling、品質變體及回退材質。

現有 `Room` 繼續負責房間拓撲、可選牆面、放置及碰撞；新模組只消費穩定的房間和展品資料，不接管編輯器狀態。

## 資料與相容性

- `RoomSize` 可加入白盒風格與材質相關選項，但所有新欄位必須有預設值。
- 現有展覽匯入時若缺少新欄位，自動套用相容預設，不改寫原始展覽內容。
- 所有新建展覽使用白盒博物館預設。
- 使用者已自訂牆色、地板色、透明度或材質時，不應被新預設覆蓋。
- 匯出及同步格式保持向後相容；多人同步只傳送場景設定，不傳送已計算的燈光實例。

## 品質分級

目標為桌面與手機平衡，沿用並擴充現有 performance profile。

### Quality

- 完整建築細節與 PBR 貼圖。
- 主要展品射燈可投射陰影。
- 較高陰影解析度、適量接觸陰影及 SSAO。
- 合理 DPR 上限，避免高像素密度裝置無限制增長。

### Balanced

- 保留主要建築細節及 PBR 材質。
- 限制同時啟用的投影射燈數量。
- 降低陰影及後處理品質。
- 維持展品照明層次，不回退成單一平均環境光。

### Low

- 簡化牆腳線及燈軌幾何，停用非必要裝飾。
- 使用低解析度材質或基本 PBR 回退。
- 僅保留少量或單一主要投影光源。
- 停用 SSAO、接觸陰影及其他後處理。

自動模式根據裝置記憶體、CPU 核心、指標類型及 viewport 判斷；使用者仍可手動切換品質。

## 穩定性修復

### 公開展覽循環更新

- 找出造成 Zustand selector 或 effect 每次 render 產生新引用的來源。
- 修復 React maximum update depth，而不是以延遲或錯誤邊界掩蓋問題。
- 公開展覽載入、匯入場景及切換至 view mode 各只應觸發必要更新。

### 登入導向

- `RequireAuth` 在已位於登入頁時不得再次導向登入頁。
- `returnTo` 只記錄原始受保護路徑，不可重複包裹現有登入 URL。
- 無登入狀態下進入建立頁，應得到一個穩定且可返回的登入 URL。

## 錯誤處理

- 必要場景資料錯誤顯示可重試的明確狀態。
- 非必要材質、HDRI 或裝飾資產錯誤只降級相關視覺。
- WebGPU 初始化失敗時回退 WebGL，不中止展覽。
- Console 不應持續輸出相同資產或 render loop 錯誤。

## 驗收與測試

### 功能驗收

- 新建展覽自動呈現白盒博物館風格。
- 現有展覽可正常載入，原有自訂設定保持不變。
- 編輯模式的牆面選取、展品放置、移動、刪除和 undo/redo 正常。
- 新增或移動展品後，照明能合理更新。
- 公開展覽及未登入導向不再出現循環更新。

### 視覺驗收

- 以空白新展覽及「澳門博物館」場景製作改造前後截圖。
- 桌面檢查 1440 × 900；手機檢查 390 × 844。
- 白牆保留細節，不過曝、不偏藍。
- 地板紋理比例合理，斜角無嚴重模糊或閃爍。
- 展品與牆面、展台與地面之間有可信接觸感。
- 陰影無明顯 acne、條紋、漂浮或大幅抖動。
- UI、Canvas 及載入狀態沒有重疊或裁切。

### 效能驗收

- 桌面 Quality 模式目標為流暢 60 FPS 級體驗。
- 一般手機 Balanced 模式目標為穩定 30 FPS 或以上。
- 場景初始化後不得因逐幀 React state 更新造成持續重繪。
- 記錄主要貼圖、draw call、投影光源和後處理的效能成本。

## 非目標

- 不更換為 Babylon.js、PlayCanvas、Unity WebGL 或 Unreal Pixel Streaming。
- 不重建完整資產管理平台。
- 不加入即時全局光照、path tracing 或重型 volumetric effects。
- 不改變現有多人、AI 導覽或展覽資料模型，除非穩定性修復確實需要。

## 實施順序

1. 修復公開展覽循環更新及登入導向。
2. 建立材質載入與品質回退基礎。
3. 改造全局環境、背景及基礎照明。
4. 加入模組化建築細節。
5. 加入展品導向的軌道燈。
6. 接入品質分級及手機降級。
7. 完成功能、視覺及效能驗收。
